CONFIRMED FINDINGS

1. [P1/P2] New support-aware metrics still accept old unmasked cached scores.
   code/project10/evaluation/evaluate_synthesis.py:39 keeps metric version
   v2_canonical_spatial while this commit changes what L1, PSNR, correlation
   and SSIM measure. Resume at 475-492 accepts prior rows with matching file
   hashes and that unchanged version, without requiring Reference_Coverage.
   Actual main() probe supplied a correctly hash-matched prior row from the
   old unmasked metric contract. It retained L1=550, made zero metric calls,
   and kept the row without Reference_Coverage. Fresh supported-region L1 for
   those inputs is 0. Thus unchanged image hashes do not establish compatible
   measurement semantics. Bump the metric version, validate cached schema,
   and reject incompatible merge inputs. --overwrite forces recomputation
   as an immediate workaround, but default resume remains wrong.

2. [P2] SSIM bounding rectangles still include unsupported reference pixels.
   evaluate_synthesis.py:186-204 takes the support's bounding rectangle and
   computes ordinary SSIM over it. An oblique source can have unsupported
   corners inside that rectangle; it does not consist entirely of valid
   SSIM windows. The function therefore contradicts its support-only contract.
   Actual NIfTI reproduction: a rotated 16x16x8 reference resampled onto a
   32x32x8 grid yielded 21.484375% reference support. Changing only unsupported
   pixels changed SSIM from 1.0 to 0.5195749931, while supported L1 remained
   0 in both cases. Independent and primary-reviewer probes agreed.
   Additionally, line 215 returns SSIM=0 when no valid slices/windows are
   collected (for example a perfectly matching narrow supported strip),
   conflating unavailable measurement with a measured poor score.
   Compute an SSIM map and average only fully supported windows, using the
   complete window footprint; report NaN and valid-window counts when none
   qualify. Do not substitute the bounding box or zero for missing evidence.

3. [P2] Area-pooled latent support misses actual encoder dependencies.
   training/train_stage2_synthesis.py:480-489 and the validation counterpart
   now mask latent MSE using area-downsampled target_support >0.99. This is
   an improvement over ignoring support, but not encoder receptive-field
   validity: autoencoder_3d.py:98-122 contains convolutions and spatial
   GroupNorm, so unsupported input can influence retained latent positions.
   Actual dataset/encoder probe: a 64-cubed patch with 62x64x64 target extent
   passed the new 95% threshold (96.875% support). The area mask retained
   87.5% of latent slots. Changing only the unsupported input slices changed
   retained latent values by maximum 0.970737 and mean 0.138880.
   This used the actual production autoencoder class with reduced channels
   and random weights, not a trained checkpoint or measured model-quality
   result. It demonstrates dependency leakage that local pooling misses.
   Require full observed target support, or implement support-safe encoding
   and loss rules accounting for convolution footprints and global spatial
   normalization. Simple latent-mask erosion alone cannot undo GroupNorm's
   dependence on unsupported values elsewhere in the patch.

4. [P2] Worker merge still permits different runs with distinct subjects.
   evaluate_synthesis.py:320-326 checks run_id only when that optional column
   is present, while main() writes no run_id or assignment/completion manifest.
   Duplicate-hash/metric checks only help when runs share a subject name.
   Actual merge_worker_csvs probe supplied two expected, current-version worker
   files with disjoint subjects and no run IDs, representing old/current L1
   999/1. Both were accepted and reported mean L1=500. File naming and a common
   metric implementation version do not prove a common cohort/run.
   Generate and require shared run/assignment identity for every shard,
   including empty-worker completion records. Validate expected subject sets,
   completion and compatible inputs before consolidating a cohort. Reject
   absent/unknown run provenance instead of making that check optional.
