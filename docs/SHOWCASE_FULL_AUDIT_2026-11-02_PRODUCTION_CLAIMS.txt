CONFIRMED FINDINGS

1. [P1] Empty consensus masks are classified clean and accepted for training.
   code/evaluation/evaluate_multi_model_ensemble.py:535-540 gives empty/empty
   organ Dice and IoU 1.0; inter-model agreement at 570-578 does the same.
   Aggregation/triage at 602-623 imposes no foreground eligibility gate.
   Two independent actual evaluate_subject() probes with two all-background
   8-cubed masks returned SUCCESS, CLEAN_HIGH_CONFIDENCE, consensus Dice 1,
   inter-model Dice 1, entropy 0 and zero foreground components.

   The new docs/manifests/ensemble_phase3_audit_summary.csv reports all four
   consensus Betti counts zero in 903 of 1,632 rows, including 405 of the 408
   CLEAN_HIGH_CONFIDENCE rows. These are archived measurements, not a fresh
   assertion that the current remote masks are empty; their contents require
   investigation before treating this archive as evidence of a usable pool.
   The actual current function independently reproduces the underlying failure.

   A downstream actual discover_phase2_dataset() probe with a valid 16-cubed
   CT, empty 16-cubed consensus label and CLEAN row returned one usable pair.
   code/training/train_mednext_phase2.py:184-205 checks readability/dimensions
   but does not reject all-background GI supervision. Thus the defect is not
   confined to a displayed score: empty labels can be admitted to training.

   Reject zero/unusable foreground before triage, export and training, and
   exclude absent organs from agreement aggregation. Quarantine/recompute
   eligibility for archived affected cases before describing the CLEAN+WEAK
   total of 873 as a verified usable pool. Do not require every organ in every
   crop; distinguish absent organs from an entirely unusable segmentation.

2. [P1/P2] Production verification declares success despite failed checks.
   code/evaluation/verify_production_results.py:337-349 ignores checkpoint
   validity, dataset/segmentation completeness flags and tables_ok. It calls
   report generation and prints ALL GATES PASSED unconditionally whenever
   execution reaches the end. Report-generation text at 268-274,294,313 and
   321-323 hardcodes complete verification, 100% completion, 1,990 verified
   lesions/zero bleed and a fully reproduced conclusion.

   Primary-reviewer controlled local probe used temporary empty results and
   the actual archived CSVs. The real file scanners reported 26 missing
   checkpoints and no CT/segmentation/synthesis outputs; only the compiler
   function was substituted to return an explicit failed-table result.
   Actual main() returned normally, printed ALL GATES PASSED and wrote the
   success assertions into a temporary report. An independent failure-injection
   probe also reproduced the unconditional success. No tracked report was
   overwritten and no production results were simulated as genuine evidence.

   Make explicit required gates control process status and report conclusions.
   Distinguish missing, failed, skipped, inventory-only and verified checks.
   Propagate compilation failure; validate output booleans rather than ignoring
   them. A generated Markdown file must not itself constitute a passing gate.

3. [P2] The production report claims checks the verifier does not perform.
   docs/PRODUCTION_VERIFICATION_REPORT_2026-11-02.md:57,80,89-90,160-162
   claims physical geometry verification, strict NIfTI eligibility, zero tumor
   bleed and fully reproduced production benchmarks. But verifier routines
   at 125-159 count filenames, and 196-233 count outputs/read an existing
   metrics CSV. They do not inspect the claimed NRRD orientation/spacing,
   validate label/probability content and subject correspondence, run JHU
   reevaluation, test lesion containment, or validate v3 run/input/checkpoint
   manifests and regenerate metric results.

   Checkpoint hashing/loadability provides an inventory fingerprint, not proof
   that these particular weights generated the reported outputs. The report
   publishes abbreviated hashes and no measured linkage from weights to each
   inference/evaluation run. The P10 verifier reads existing Pearson_R values;
   labeling them masked soft-tissue correlations is not established by this
   check or the current evaluator, whose correlation covers reference-supported
   voxels rather than a soft-tissue-only mask.

   The report also hardcodes the lesion count/zero bleed without reading a
   lesion manifest. Recompiling tables from existing CSVs is not recomputing
   their measurements under corrected spatial/support rules. These scope gaps
   remain even if every expected file exists and all Boolean gates are fixed.
   Implement the advertised checks with saved raw results/manifests and complete
   identities, or narrow the report to timestamped inventory/loadability and
   existing-report aggregation. Do not call that complete cohort reproduction.
