ASSESSMENT

The current evidence does not establish a validated improvement from automated
cleansing/distillation or clinically faithful, phase-selectable CT synthesis.
Passing software tests and inventory gates do not resolve the confirmed label,
geometry, support-provenance, cohort-independence and reporting defects below.
Some historical results may be useful exploratory measurements, but affected
benchmarks and descendant training runs need regeneration after these defects
are resolved. This audit does not establish that every historic run exercised
every defective branch, or that unavailable cluster files are absent remotely.

Evidence classes used throughout:
  CONFIRMED: source defect, local artifact content, or controlled production-path probe.
  HISTORICAL: numbers in the checked-in report/showcase, without local raw outputs.
  UNVERIFIED: cluster assets, run status, full-cohort metrics and training lineage.
  REPLAY: recomputation of rounded archived statistics, not new image measurements.
P1 means a major threat to the advertised scientific result or supervision chain.
P2 means a material validity/reproducibility gap. P3 is a narrower latent issue.

WHAT THE REPORTED RESULTS ACTUALLY SHOW

- Historic Table 1 (499 scans) reports mean Dice approximately .003 for MedNeXt
  and .001 for Swin. These do not demonstrate successful segmentation. They warrant
  label/geometry/checkpoint diagnosis before attribution to architecture quality.
- Historic JHU table reports TotalSegmentator .700, MedNeXt .489, Swin .458 and
  ensemble .061 mean Dice on the broadest model cohorts. Phase 3 MedNeXt .038,
  Pool873 .010, Phase 3 Swin .002 and Phase 3 ensemble .004 each have N=1.
  Unequal sample sizes prevent a matched phase-to-phase improvement estimate.
  Neither these numbers nor the archive demonstrate distillation superiority.
- Historic synthesis aggregates: L1 1,237.2 HU, body L1 1,348.4 HU, SSIM -.030,
  PSNR 11.2 dB and Pearson R .343. These report substantial error. The subgroup
  called High-Fidelity is selected post hoc by L1<500 and still reports body L1
  539.8 HU and R .481; this is an error stratum, not diagnostic-fidelity validation.
- Procedural tumor intensity patterns are generated using prescribed profiles.
  Observing the prescribed arterial/venous pattern verifies implementation behavior,
  not independent pharmacokinetic validity, pathology realism, or diagnostic utility.

CONFIRMED PRIORITY FINDINGS

F01 [P1] Production ensemble uses an incorrect TotalSegmentator schema.
  Source: code/evaluation/evaluate_multi_model_ensemble.py:399-414;
  compare its disconnected normalize_prediction_mask helper at :61-73.
  Actual v2 input labels 6/18/20 become GI labels 4/1/3; correct outputs are 1/3/4
  (stomach/small bowel/colon). Production-path probe returns SUCCESS with these
  wrong mappings. Wrong related maps remain in hard_threshold_autolabel.py:157-162,
  train_mednext_phase2.py:347-352 and train_swin_unetr_phase2.py:246-251.
  Consequence: corrupted consensus, agreement statistics and descendant supervision.
  Action: require explicit version/schema provenance and use one tested conversion
  in every actual production path; regenerate affected masks/rows/descendants.

F02 [P1] Ensemble/autolabel alignment and Phase 2 geometry repair are unsafe.
  Sources: evaluate_multi_model_ensemble.py:459-470;
  hard_threshold_autolabel.py:140-143,179-183;
  train_mednext_phase2.py:290-304,370-414;
  train_swin_unetr_phase2.py:218-226.
  Native GI masks align by shape without checking physical origin/direction.
  Probe: identical arrays separated by 100 mm produce inter-model Dice 1.0 and
  CLEAN_HIGH_CONFIDENCE although they do not overlap in physical space.
  FixLiarLabelAffined infers a bad header solely from differing shapes and overwrites
  a valid cropped label's affine. Probe: 16-cube label origin100mm/spacing1mm becomes
  origin0/spacing1.5,1.5,2mm beside a 32-cube CT. Required ResampleToMatchd is mentioned
  in comments but absent from the actual MedNeXt Phase 2 pipelines.
  Action: verify geometry provenance, preserve legitimate affines and resample every
  image/mask/probability tensor to a common physical reference using correct interpolation.

F03 [P1] Archived pool of 188 still contains empty-organ-inflated legacy scores.
  Sources: docs/manifests/ensemble_phase3_audit_summary.csv:2;
  evaluate_multi_model_ensemble.py:548-553,576-610,635-637;
  docs/PRODUCTION_VERIFICATION_REPORT_2026-11-02.md:80-85.
  Example BDMAP_00242385 has absent stomach, duodenum and colon in consensus and both
  models, yet perfect empty/empty scores enter its stored global .754/.75 Dice values.
  Current eligibility leaves bowel Dice .01595 and inter-model Dice0: REJECT.
  Replay of archived rounded per-organ scores using current triage_case produces
  1,598 REJECT /34 WEAK /0 CLEAN: 154 WEAK->REJECT, three CLEAN->WEAK.
  This proves aggregation inconsistency, not the exact post-fix production cohort.
  Action: recompute from input volumes with current metric version and provenance,
  regenerate training manifests, and determine which training runs inherited old labels.

F04 [P1] Ensemble resume can disconnect saved masks from the current audit rows.
  Source: evaluate_multi_model_ensemble.py:383-385,519-522,855-870.
  File existence prevents saving newly computed outputs; SUCCESS rows resume by subject
  ID without checking inputs/checkpoints/version. Probe: saved consensus has64 foreground
  voxels; replace both inputs with empty masks, rerun -> row reports0/REJECT but saved
  consensus still has64 foreground voxels.
  Action: bind input hashes, schema, configuration, code and output hashes into completion
  records; invalidate and atomically replace outputs/rows together when identity changes.

F05 [P1] Registration-created padding is incorrectly treated as observed target data.
  Sources: project10/datasets/register_multiphase_pairs.py:119-128,284-293;
  project10/datasets/multiphase_paired_dataset.py:206-215;
  project10/evaluation/evaluate_synthesis.py:85-101.
  Registration fills outside moving field of view with -1000 HU but does not preserve
  original-domain support. Dataset and evaluator create support=1 over that registered
  grid, so unobserved padding is indistinguishable from acquired air.
  Integrated probe: register8x8x4 moving image onto8-cube reference; 50% becomes fill,
  but the actual dataset accepts it with target_support1.0 and evaluator support1.0.
  Action: warp/save original moving-domain support with the final transform and propagate
  it through crop/resampling, training loss, metrics and completion provenance.

F06 [P1] Mixed-phase diffusion has no requested-phase conditioning.
  Sources: project10/datasets/multiphase_paired_dataset.py:339-345;
  project10/training/train_stage2_synthesis.py:457-479;
  project10/models/synthesis_net.py:59-83.
  Dataset phase metadata is not consumed by training; model accepts noisy latent,
  diffusion step, source latent and anatomy only. Diffusion timestep is not acquisition
  phase/time. Archive mixes1,228 venous/161 early arterial/156 late arterial targets.
  Phase-specific names cannot establish selectable physiological phase generation.
  Action: add explicit phase/time conditioning and stratified endpoints, or constrain
  the scientific task and cohort to one target phase.

F07 [P1] Stage 1 and Stage 2 do not share an independent patient holdout.
  Sources: project10/training/train_stage1_autoencoder.py:146-163;
  project10/training/train_stage2_synthesis.py:365-381.
  Stage1 discards patient grouping and randomly splits phase volumes. Stage2 separately
  splits patients, so its frozen encoder may already have seen its validation patients.
  Synthetic ten-patient/two-phase probe: both Stage1 validation patients also in train.
  Action: persist one patient-grouped development/validation/test assignment before any
  stage, including AE pretraining and preprocessing fitting; audit existing run overlaps.

F08 [P1] Stress report makes favorable claims independent of measured results.
  Source: project10/evaluation/stress_test_contrast_perturbation.py:234-239,310-325.
  Report always prints >95% retention and Zero Hallucination Confirmed. Procedure
  perturbs already generated images then compares a fixed segmenter's predictions;
  it does not test generation under noisy source inputs or independently detect lesions.
  Action: derive prose from measured endpoints and call this output-image segmentation
  consistency. Use separate generator-robustness and independent lesion/anatomy endpoints.

F09 [P1] Production verification gates do not establish their advertised completion.
  Source: code/evaluation/verify_production_results.py:171-197,422-428.
  Gate2 ignores ct_sample_ok and accepts1600 CTs despite a1632 completion claim.
  Gate4 accepts one manifest row and ignores content, cohort linkage and WEAK eligibility.
  Gate5 requires only1500 pair rows plus a toy kinetics check; zero registrations,
  DVFs, synthetic volumes and evaluated results can all pass.
  Controlled actual-main probe with injected function returns and temporary output
  produced ALL GATES PASSED with failed CT geometry, a one-row manifest and zero P10
  generated/evaluated outputs. This probes gate logic, not real asset existence.
  Action: exact expected subject sets, readable/valid geometry/content, complete current
  row provenance, eligible labels and per-worker/cohort completion must be enforced.

F10 [P2] Missing/corrupt Stage 1 CTs silently become blank-air training examples.
  Source: project10/training/train_stage1_autoencoder.py:175-180.
  Every loading exception substitutes -1000HU. Probe nonexistent CT yields a valid
  [1,8,8,8] tensor with unique normalized value-.5. Failures can contaminate training
  and improve apparent reconstruction on trivial blank validation data.
  Action: preflight cohort integrity and fail or explicitly exclude/count corrupt inputs
  before fixed splits; record every exclusion.

F11 [P2] Sampler fallback and schedule provenance permit mismatched generation.
  Sources: project10/evaluation/sample_multiphase_diffusion.py:150-179,479;
  project10/training/train_stage2_synthesis.py:132-151,294,435.
  Broad preprocessing fallback replaces affine with diagonal spacing. Forced-fallback
  probe changes a valid CT origin100/200/300mm to0/0/0. Nondefault --timesteps is not
  checkpointed while sampler always uses1000. These are conditional code defects;
  this audit did not establish which historical runs used fallback/nondefault settings.
  Action: preserve transformed geometry or fail; checkpoint and validate full diffusion
  schedule, preprocessing and architecture configuration.

F12 [P2] Statistical inference treats repeated patients as independent scan rows.
  Source: code/evaluation/statistical_significance_test.py:49-59,63-95,145-152.
  Bootstrap draws individual rows; paired tests do not account for sibling phases;
  repeated subject IDs can also create many-to-many merges without validation.
  JHU's11 scans derive from5 patients and reused/propagated expert annotations.
  No family-wise/FDR correction is applied to the organ/metric comparison family.
  Action: matched patient-level cohorts, cluster bootstrap or patient summaries,
  explicit unique pairing and multiplicity policy. N=1 results remain descriptive.

F13 [P2] Segmentation splits and scaling evaluations do not establish independence.
  Sources: training/train_mednext.py:334-348; train_swin_unetr.py:273-287;
  train_mednext_phase2.py:556-570; evaluation/eval_scaling_checkpoints.py:60-79;
  training/run_scaling_sweep.py:411-418,575-580.
  Segmentation folds split scans, not patient groups. Scaling posthoc evaluator takes
  CLEAN/training-eligible cases without excluding checkpoint training patients; its
  default labels are consensus pseudo-GT. Scaling runner independently samples training
  and accepts gold-standard validation without excluding overlap, then selects the best
  checkpoint on that validation. This is not an untouched external test.
  Action: saved patient identity and fold manifests; remove overlap at every stage;
  separate tuning/selection from final evaluation. Actual historical overlap is unverified.

F14 [P2] Scaling expert-label conversion has independent schema/coordinate defects.
  Sources: training/run_scaling_sweep.py:176-207,723-745.
  Its remapper assumes5=ileum and6=colon, but local JHU headers say5=colon and6=rectum.
  It merges colon into bowel and promotes rectum to colon when applied to JHU labels.
  NRRD conversion copies LPS directions/origin into a NIfTI affine without LPS->RAS.
  Probe LPS origin100/200/300 yields NIfTI origin+100/+200/+300 instead of-100/-200/+300.
  4D files are collapsed by segment index without using per-segment header semantics.
  Action: use verified header label definitions and coordinate conversion for this path;
  compare converted masks to the established SimpleITK expert evaluator.

F15 [P2] Ignored/absent organ policies and partial checkpoint loads bias comparisons.
  Sources: train_mednext_phase2.py:768-773;
  run_scaling_sweep.py:302-324; eval_scaling_checkpoints.py:95-97,119-137.
  Phase2 validation turns255 ignored voxels into background but does not mask predictions.
  Scaling deliberately returns1.0 for empty/empty organs; JHU/ensemble returnNaN.
  Probe all-empty four-organ tensors -> Dice[1,1,1,1], HD95 allNaN. Different endpoints
  are not directly comparable; missing-organ HD95 exclusions need failure-rate reporting.
  Scaling checkpoint loading uses strict=False, ignores missing keys and reuses a model;
  incomplete checkpoints may leave uninitialized or previous-model parameter values.
  Action: valid-voxel masks in metrics, explicit organ eligibility/failure counts and
  strict architecture/key compatibility before accepting any checkpoint result.

F16 [P2] Manuscript/report generators can certify incomplete or unrelated evidence.
  Sources: manuscript/compile_manuscript_tables.py:90-104,348-362;
  evaluation/verify_production_results.py:310-315,373-374,391-393.

F17 [P2] Automated tests can overwrite the tracked production audit trail.
  Source: tests/test_audit_remediation_regressions.py:1756-1765.
  Test calls actual verifier main while mocking only manuscript compilation, so report
  writer overwrites docs/PRODUCTION_VERIFICATION_REPORT_2026-11-02.md. Observed during

F18 [P2] Paired synthesis cohort lacks evidence of temporal/examination matching.
  Sources: docs/manifests/multiphase_pairs.csv;
  project10/datasets/discover_multiphase_cohort.py:185-204.
  All1545 archived rows have missing source and target examination dates and same_day=False.
  False here means unverified, not proof of different-day acquisition. Discovery chooses
  the latest available NCCT and all noncontrast-target rows for a patient by default;
  same-day filtering is optional. Patient identity alone cannot establish that observed
  differences are solely contrast dynamics rather than anatomy/pathology over time.
  Action: recover examination-level identity/timing or explicitly qualify longitudinal
  pairs, stratify/exclude uncertain matches and review registration independently.

F19 [P3] Some ensemble physical metrics assume fixed voxel spacing.
  Source: evaluate_multi_model_ensemble.py:555-560 and metric default arguments.
  HD95/volume/surface calls use default1.5/1.5/2mm rather than reference-header spacing.
  This is correct only when the actual accepted reference grid has that spacing.
  Action: pass validated reference spacing and retain it in metric provenance.

METHODS AND INTERPRETATION LIMITS

- Frozen-segmenter agreement in run_clinical_turing_test.py:145-152 passes eligible
  cases at meanDice>=.70 with any eligible organ. It is neither a human reader Turing
  experiment nor independent anatomy, lesion or clinical-interchangeability validation.
  Report detection/eligibility counts per organ alongside agreement and failed cases.
- Diversity weights use binary foreground overlap, not independent accuracy; ECE is
  measured against the same ensemble consensus. These are internal consistency measures,
  not expert calibration or guaranteed label correctness. Betti0 counts components,
  not all topology or anatomical correctness. Thresholds need independent adjudication.
- A synthetic lesion containment check can show zero edits outside a known lesion
  mask; it cannot verify every production lesion, correct host-organ placement, clinical
  enhancement distributions, realistic margins, or downstream benefit.
- Cross-phase propagated JHU labels are imperfect references and repeated measurements.
  Patient-specific motion/deformation and propagation rules need adjudicated validation.
- README still describes SPADE-Diffusion/VQ-VAE, while production SHOWCASE documents a
  deterministic continuous AE (use_vq=False). Report exact executed configuration.
- requirements.txt/setup.py give broad lower bounds and differing SciPy constraints;
  a passing current local environment is not a reproducible historical HPC environment.
  Save exact package/CUDA/container versions with each result.
