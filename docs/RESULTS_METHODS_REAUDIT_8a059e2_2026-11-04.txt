CONFIRMED FINDINGS

1. [P1] Incomplete or unsuccessful execution still passes run-proof verification.
   code/evaluation/verify_production_results.py:605-612 accepts evaluated subjects
   as a subset of manifest subjects, without exact cohort coverage, total_files
   consistency, worker assignments or mandatory successful completion metadata.
   The alternative sidecar branch at :625-640 checks only positive assigned and
   scored counts plus a success-like status. It does not require equal counts,
   zero errors or all workers; :639 explicitly accepts missing subject coverage.
   Actual two-case evaluator output first passes normally. Removing one of its
   two metric rows still passes cohort_lineage_ok. Removing the manifest and
   substituting one sidecar with assigned=100, scored=1, error_count=99, worker 7
   of 8 and no case list also passes. These are isolated lineage-flag probes;
   they do not establish that every production gate passes.
   Required repair: use the evaluator's strict manifest/worker merge contract,
   require exact complete assignments and coverage, and reject failed, missing,
   contradictory or incomplete workers by default.

2. [P2] Metrics are not authenticated against current source volumes and support.
   The same verifier run-proof block (:598-640) ignores recorded fake/real/support
   hashes and execution configuration. A manifest with total_files=999 and bogus
   fake, real and support hashes is accepted. Replacing a registered reference
   with different finite voxel values also leaves cohort_lineage_ok=True while
   existing metrics and input hashes remain stale.
   The NaN fix checks usable numeric payloads; it does not prove those payloads
   were the ones scored. Revalidate current metric input hashes, reference/support
   identities, model/checkpoint/config identities and complete row provenance.
   A genuine evaluator-produced two-case result is the positive control here.

3. [P2] Evaluation factory selection still overrides explicit model provenance.
   code/evaluation/eval_scaling_checkpoints.py:345 selects local MedNeXt whenever
   architecture is MedNeXt-B, even when factory explicitly says nnunet_mednext.
   Thus a declared nnU-Net kernel-3 model becomes the local kernel-7 model.
   Actual probe confirms the selected class is mednext.MedNeXt with 7-cube kernels.
   Existing Phase 1/2 MedNeXt producers also use create_mednext_v1 with default
   kernel 3 and emit architecture/model_id/kernel_size without factory:
   train_mednext.py:392-405,442-447 and train_mednext_phase2.py:557-560,616-619.
   Those configurations encounter the same local-first selection when available.
   Conversely, :352 tries nnU-Net without checking whether the manifest declared
   UNet, and :365 silently falls back to UNet for unknown architecture/factory.
   An actual unknown-configuration probe was accepted as MONAI UNet.
   This can make supported checkpoints fail loading rather than yield valid
   evaluation. No silent wrong production scores were demonstrated. The official
   nnunet_mednext dependency is absent locally, so its real checkpoint round trip
   remains untested; dispatch precedence is verified independently of that absence.
   Required repair: dispatch on explicit factory, define a compatible legacy
   manifest policy, validate full configuration, and fail when the requested
   implementation is unavailable instead of substituting another architecture.

4. [P2] Complete gzip checksum validation is still missing.
   code/evaluation/verify_production_results.py:469-489,528-542 checks trailer
   size and materializes voxel arrays, but does not explicitly validate the CRC.
   On this environment, reading the voxel array does not consume/validate the
   gzip trailer. With otherwise accepted actual two-case evaluator evidence,
   flipping one CRC byte of a registration, then independently a DVF, leaves
   cohort_lineage_ok=True. Python gzip.decompress rejects both as corrupt.
   This fixture preserves the voxel bytes; it demonstrates missed container
   corruption detection, not that incorrect voxel values were measured.
   Required repair: read each required compressed stream through EOF with checksum
   validation (or equivalent), in addition to geometry, payload and finite checks.
