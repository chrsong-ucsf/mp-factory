CONFIRMED REMAINING FINDINGS, PRIORITIZED

1. [P1] Scaling source-schema selection can erase valid supervision.
   code/training/run_scaling_sweep.py:119 chooses jhu only from the directory name;
   everything else becomes bdmap. find_cases():124-128 applies this to canonical
   gi_mask.nii.gz and even a single binary stomach.nii.gz fallback. The explicit
   BDMAP map then correctly treats label1 as esophagus/background, but label1 in a
   canonical GI mask is stomach. Actual find_cases plus RemapGILabelTargets probe
   transforms a valid stomach-only label to zero foreground.
   Required: verified source schema per record/configuration; explicit merging of
   binary organ files; reject unresolved schemas rather than infer from path spelling.

2. [P2] Scaling crops before resampling and violates the requested training ROI.
   run_scaling_sweep.py:228-236 inserts CropForeground/Pad/RandCrop at fixed indices
   after another transform was added. Actual order is label alignment, cropping,
   padding, random crop, THEN Spacingd and intensity scaling. A native1mm input and
   requested32-cube ROI produces two tensors shaped(1,22,22,16), not(1,32,32,32).
   This changes training context and can violate batching/backbone divisibility.
   Required: spacing/intensity preprocessing before final fixed-size random cropping;
   test mixed native spacings and actual returned training tensor shapes.

3. [P1] Default sampling silently conditions arterial targets as venous.
   project10/evaluation/sample_multiphase_diffusion.py:589-600 derives auto phase
   from filename words and otherwise defaults to venous3. Registration filenames
   at datasets/register_multiphase_pairs.py:373-375 contain only source/target IDs.
   The authoritative phase_target in the registration manifest is not read.
   Archive check:1545 ID-only names, none with phase tokens;161 early arterial and
   156 late arterial targets would all follow the venous fallback under defaults.
   Explicit --target_phase now works; this is a default-resolution bug, not proof
   that every historic output was generated using that default.
   Required: join IDs to manifest phase metadata; fail if unresolved or conflicting;
   verify acquisition phase in output identity and reference matching.

   Matching AE/Stage2 RNGs now aligns identical patient universes, but Stage1 splits
   all paired-manifest patients and Stage2 re-splits registration-success patients
   (train_stage1_autoencoder.py:146-161; train_stage2_synthesis.py:360-388).
   Probe:10-patient AE valP8; same10 diffusion valP8; after registration attrition
   leaves9 patients diffusion valP7, which the AE trained on.
   Segmentation Phase1 MedNeXt :336-351 and Phase2 Swin :359-371 still split scans.
