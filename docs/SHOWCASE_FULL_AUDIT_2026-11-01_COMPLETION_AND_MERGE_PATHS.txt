CONFIRMED FINDINGS

1. [P2] Failed partial evaluation runs can publish an incomplete cohort.
   code/project10/evaluation/evaluate_synthesis.py:789-805 writes worker
   metadata with status='completed' even when error_count is positive, before
   the worker raises its failure. Merge at 354-376 checks metadata run ID but
   ignores status/error_count/assigned-versus-scored counts. It also never
   checks that merged subjects cover the manifest's expected input/assignment
   set. Presence of every shard is not proof that every assigned case succeeded.
   Actual unmocked three-case/two-worker probe: B's reference was missing;
   worker 0 raised RuntimeError after writing A, and worker 1 scored C.
   merge_worker_csvs then succeeded and published only A and C, two of three
   assigned cases, despite the recorded error and incomplete manifest coverage.
   Use truthful completion states, reject failed/incomplete worker metadata,
   validate worker identity/counts and expected subject sets, and require
   explicit partial-result handling if a reduced cohort is intentionally wanted.
   Failed jobs must not become an apparently complete benchmark through merge.

2. [P2] Merge-only CLI can silently bypass available input verification.
   main() at evaluate_synthesis.py:594-604 always supplies fake_dir/real_dir
   from argument defaults. Manifest-path recovery at 338-344 only replaces
   None, so nonexistent default directories suppress the valid custom input
   paths stored in the manifest. At 457-461, inaccessible directories simply
   bypass current-file hash revalidation rather than producing an error.
   Actual CLI probe used an explicit run ID and custom inputs/output. After
   initial two-worker scores of L1=1, reference B changed from 101 to 103 HU
   and only worker 0 reran. Running --merge_only with the custom output and
   worker count, without repeating the input-directory flags, accepted B's
   stale score of 1 instead of the current expected 3. The manifest remained
   accessible. Supplying the true input directories correctly raised ValueError.
   Resolve merge inputs from the recorded manifest when overrides are omitted;
   distinguish omitted options from explicit invalid paths. Fail clearly when
   required input verification cannot run, rather than silently dropping that
   guarantee. Explicit run names must not override content verification.

partial-reference inference still contains fill air outside observed support.
Convolutions/normalization can use that context when predicting inside support.

this is recorded as an unverified production limitation, not an additional
