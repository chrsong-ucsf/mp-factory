     AttributeError: 'Namespace' object has no attribute 'output_dir'

   discovery, split construction and manifest persistence, before model allocation.

2. [P1] Scaling fails before model allocation on undefined run_dir.
   code/training/run_scaling_sweep.py:580 writes train_manifest.json through run_dir,
   which is never defined. Actual run_single_sweep raises NameError. The real n_dir
   is only created later at:621-622. Create the correct run directory before writing
   membership and exercise a real runner call in regression verification.

3. [P2] Scaling collapses unknown patient names into a dataset prefix.
   run_scaling_sweep.py:530,537,552,576 uses name.split('_')[0] outside the known JHU
   map. CV_1001_P0 and CV_1002_P0 become one patient CV. Actual sweep split probe
   reports two scans/one validation patient and zero training scans before item2.
   The expert-validation branch can exclude unrelated patients by the same prefix.
   Use verified patient metadata and one shared extraction policy; require nonempty
   independent training/validation populations after exclusion and before fitting.

4. [P1/P2] Empty P10 validation populations become a false perfect best checkpoint.

5. [P2] Per-checkpoint evaluation still admits training-patient siblings.
