Confirmed conditional software defect introduced by the native-mask output change. No model or image execution required.

Producer MedNeXt: code/prediction/predict_mednext.py:143-157 constructs pred_np with the preprocessing/resampled affine. :159-163 resamples ONLY the hard segmentation onto orig_nii's native CT grid and writes that mask. :165-168 saves softmax(pred_logits[0]) directly as NPZ field probs, retaining the resampled inference grid and recording no affine.
Producer Swin: code/prediction/predict_swin_unetr.py:183-203 performs the same native hard-mask resampling; :205-208 saves untransformed inference-grid probabilities without an affine.
Consumer: code/evaluation/evaluate_multi_model_ensemble.py:436-457 records loaded native-mask geometry. :480-485 resamples each probability channel using loaded_niis[i].affine, which is now the NATIVE MASK affine, not the probability grid's resampled affine. The NPZ contains no geometry field that could recover the correct transform.

Trigger: --save_probs AND preprocessing changes spacing, orientation, origin, or crop grid relative to the native CT. For example, a probability voxel at x-index10 on a 1.5mm inference grid denotes x=15mm (equal origin); interpreting it using a native 0.75mm mask affine places it at x=7.5mm. Equal array shape does not guarantee equal physical geometry either.
Impact: hard masks can be correctly native-aligned while probability-driven consensus/uncertainty/ECE are calculated from displaced or scaled probabilities. Shape-based conditional resampling cannot fix an incorrect source affine. This can invalidate comparisons of the amended prediction pipeline, and a generic synthetic probability-alignment unit test does not validate this producer/consumer combination.
Boundary: no error is implied when probabilities are not saved/used, or when preprocessing leaves the native grid unchanged. Actual historical affected cases/results were not quantified here.
Remedy: either resample every probability channel to native space with appropriate interpolation and renormalization before saving, or persist the probability grid affine and shape in the NPZ and make the consumer use those fields with explicit legacy policy. Test an end-to-end native CT -> inference grid -> mask+NPZ -> ensemble example with nontrivial native spacing/orientation, verifying the same anatomy lands in the same world coordinates. Regenerate affected probability artifacts and derived consensus/results.
