CONFIRMED REMAINING FINDINGS

1. [P1] P10 synthesis and clinical metrics still use a different spatial grid.
   Sampler preprocessing now calls common_spatial.preprocess_single_volume,
   which uses MONAI. run_clinical_turing_test.py:89-122 and
   evaluate_synthesis.py:51-85 retain manually rounded SimpleITK resampling.
   Exact-function20-cubed1mm ramp to8-cubed probe:
   -Sampler xHU:45,60,75,90,105,120,135,150.
   -Clinical evaluator xHU:30,45,60,75,90,105,120,135.
   -Synthesis evaluator xHU:30,45,60,75,90,105,120,135.
   The center-crop change alone did not unify resampling extents. Route every
   evaluation through the common transform or resample the target to the
   actual generated NIfTI physical reference. Direct array subtraction and
   anatomical agreement are not valid until correspondence is established.

2. [P1] Inference organ conditioning still discards physical alignment.
   sample_multiphase_diffusion.py:212 independently preprocesses each mask,
   discards its affine, and receives no source CT/reference grid. A fresh
   exact-loader probe shifted a GI mask1000mm in X. With strict conditioning
   enabled, it still returned512 duodenum voxels, identical to the unshifted
   mask's conditioning tensor. Independently centering arrays is not physical
   registration. Pass the actual CT patch reference and resample the mask
   into it; reject zero/insufficient overlap instead of checking array support.

3. [P1/P2] Required conditioning remains optional in the production launcher.
   The loader's require_conditioning option defaults false, and
   run_p10_sample_multiphase.sbatch omits --require_conditioning. Missing or
   unusable masks can therefore still become neutral background priors even
   for a checkpoint trained with anatomical conditioning. The strict option
   is implemented, but does not protect the default production command.
   Make conditioning requirements part of the checkpoint/run contract and
   enforce them in the launcher and sampler.

4. [P1/P2] Default tumor-mask discovery can suppress a valid host mask.
   generate_multiphase_tumors.py:67-88 returns the first existing mask.
   Default GI directories at149-151 precede the full-body directory; main
   at245/249 never retries after host extraction rejects that first mask.
   Fresh probe: a GI label4 mask was selected and yielded zero liver voxels,
   despite1000 valid liver voxels in a later full-body candidate. Search by
   verified requested organ/schema and sufficient physical overlap, rather
   than file existence. Report rejected candidates and skipped lesions.

5. [P2] Native-grid rendering/export contradicts canonical-RAS claims.
   The corrected process_subject now uses native CT arrays at
   generate_showcase.py:608-609 and writes native geometry at721. Orthoview
   axis labels at205-214 and 3D views at327-328 still assume RAS/+Z superior;
   the showcase promises canonicalRAS+. An actual process_subject probe
   exported LAI orientation, not RAS. Physical alignment is now correct, but
   head-up orientation and anatomical axis labels are not guaranteed. Either
   canonicalize the aligned common grid or derive labels and mesh coordinates
   from the full physical transform, and describe the exported space accurately.

6. [P2] Annotation filenames are still being counted as patients.
   compile_manuscript_tables.py:154-156 prioritizes source_nrrd over even an
   available patient_id. The radiologist feedback guide:22-26 explicitly
   identifies113 and114 as sibling phases of one patient with separately
   edited annotation files. Therefore six NRRDs do not establish six patients.
   The new test asserts the same incorrect proxy. Prefer verified patient_id,
   resolve known phase groups, and call annotation counts annotation counts.

7. [P2] Six new regression tests mostly test independent demonstrations.
   tests/test_audit_remediation_regressions.py:29-72 exercises SimpleITK
   directly;76-102 defines its own filtering; subsequent tests copy mapping,
   gating, splitting, and counting logic. They do not call the production
   evaluator/loader/compiler. They could pass while the old defects remained
   in application code, and do not establish coverage of all16 prior findings.
   Use actual application functions with temporary inputs, including shifted
   and reoriented grids, uncertainty artifacts, native1mm resampling, and
   independent patient metadata. Direct audit probes independently verified
   the P9 fixes; the six new pytest passes alone did not prove them.

8. [P2] The new TotalSegmentator citation has the wrong DOI and no value trace.
   SHOWCASE.md and compile_manuscript_tables.py:117 cite10.1148/radiol.230297.
   The actual2023 paper's DOI is10.1148/ryai.230024, in Radiology: Artificial
   Intelligence. The publisher/PMC paper reports overall test Dice0.943 and
   links per-structure results; merely citing it does not demonstrate the
   origin of this table's literal stomach0.000/duodenum0.412/etc. Keep those
   values unverified until their exact table/dataset/version/subset and
   aggregation can be reproduced. Do not replace them with the paper's overall
   Dice, which measures a different endpoint.
   Primary source: https://pmc.ncbi.nlm.nih.gov/articles/PMC10546353/
   Publisher DOI: https://doi.org/10.1148/ryai.230024

9. [P2] Historical output identity remains unverified during sampling reruns.
   sample_multiphase_diffusion.py:450-457 accepts and skips any existing finite
   128-cubed volume without comparing input/checkpoint/schema/transform identity.
   Historically leaked or differently cropped outputs can therefore survive a
   corrected run. Mixed generation failures can also still return success;
   only all-attempted-failed raises at542-543. Keep per-output provenance and
   distinguish complete, partial, skipped-unverified, and failed runs. Prefer
   a new versioned output directory for corrected production regeneration.

10. [P2] Available figures/tables still mix historical evidence and current code.
    No PNG changed in this remediation. Three JHU comparisons retain old
    class mapping/concordance/title scores; their detailed case sections still
    make current-sounding accuracy claims, even though the conclusion now
    labels cases1-3 legacy. Keep legacy qualification beside every affected
    claim and regenerate all evidence from one audited run. The P10 comparison
    and tumor images remain heavily saturated; additional explanatory prose
    does not validate anatomical/vascular fidelity. Tables for50 JHU rows,
    1067 synthetic volumes, and1990 lesions have no local raw results/manifests
    from which corrected values can be independently regenerated.
