CONFIRMED FINDINGS

1. [P1] Training still accepts physically disjoint anatomy conditioning.
   code/project10/datasets/multiphase_paired_dataset.py:109-129,243-254
   independently resamples and center-crops NCCT, contrast target and mask.
   Preserving each affine does not place these arrays on a shared reference.
   train_stage2_synthesis.py:457-479 consumes them by array index. An actual
   MultiphasePairedDataset probe accepted an 8-cubed all-foreground mask
   translated +1000 mm: all 512 foreground voxels remained; CT origin was
   [0,0,0], mask origin [1000,0,0]. Inference now rejects this same geometry.
   Resample mask and target onto the actual NCCT grid before shared cropping;
   reject insufficient overlap and test the production dataset, not just a
   standalone spatial transform. Retaining metadata alone is insufficient.

2. [P1/P2] Strict inference aborts before trying a valid later mask candidate.
   code/project10/evaluation/sample_multiphase_diffusion.py:300-313 raises
   inside the candidate loop when the first existing mask is unsuitable.
   Actual loader probe: first GI label-2 mask, explicit total schema, strict
   conditioning, and later valid full-body label-19 mask produced ValueError
   on the first candidate. Default discovery checks GI directories first;
   checkpoint metadata now correctly forces strict conditioning. Together
   these can block a usable production case. Continue after rejected
   candidates; raise only after exhausting them, retaining rejection reasons.

3. [P2] Generation resume does not identify the current inputs or transform.
   sample_multiphase_diffusion.py:478-501 accepts an existing output using
   diffusion SHA, AE SHA, task, finite values and 128-cubed shape. It skips
   before resolving the current NCCT at 510 onward. Sidecar fields at 573-585
   omit NCCT/mask content hashes, sampling steps, seed, and preprocessing/code
   identity. Outputs with an earlier spatial transform or changed inputs can
   therefore survive under unchanged weights/schema. This is a static control-
   flow finding, not a claim that a particular cluster output is stale.
   Compare the complete generation contract before skipping, or regenerate
   into a new versioned directory with recorded input and transform identity.

4. [P2] Evaluation resume retains stale measurements for regenerated volumes.
